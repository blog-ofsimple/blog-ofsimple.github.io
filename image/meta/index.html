Image Meta 가이드

이미지 파일의 EXIF/메타데이터를 브라우저에서 안전하게 읽어옵니다. 위치 정보(GPS)가 있으면 지도 링크를 제공하며, 코멘트를 추가해 PDF로 저장할 수 있습니다. 모든 처리는 로컬에서 수행됩니다.

사용법 요약

  1. 이미지 선택(여러 장 가능)
  2. 메타정보 확인: 촬영 기기, 노출, GPS 등
  3. 코멘트/라벨 추가
  4. PDF로 저장

FAQ

  • 보안: 서버 업로드 없음, 브라우저 내 처리
  • GPS: 위/경도 존재 시 외부 지도 링크 제공
  • PDF: 이미지+코멘트 페이지 구성
