Vocadio Support

Support for Vocadio, an app for creating decks and items and managing study sessions, quizzes, and notes.

App information

  • App name: Vocadio
  • Version: 1.0.0
  • Main features: decks, items, study, quizzes, notepads, PDF and Excel, and data backup
  • Platforms: iPhone and iPad

Quick start

  1. Create a deck from the Decks tab.
  2. Open the deck and select Add item to enter the material you want to learn.
  3. Open the Study tab and choose a deck and study range.
  4. Use the Quiz tab to answer items from the same deck and review results and incorrect answers.

Using decks and items

  • A deck groups items that you want to study together. Each deck can have its own name, description, and card color.
  • Supported item types are word and meaning, term and description, sentence blanks, and multiple choice.
  • Search options let you choose prefix or contains matching and the fields to search. Type filters and sorting can be applied at the same time.
  • In the item editor, swipe left or right to review and edit adjacent items.
  • Select Add another to save the current item and immediately enter another item of the same type.
  • You can select and delete decks or items, or swipe an individual item to the left to delete it.

Studying

  • After choosing a deck, you can search its item list and apply an item-type filter and sorting.
  • Choose all items, the filtered results, or a range based on an anchor item, then start in sequential or shuffle order.
  • During study, select the current position to move quickly through a large set using a number, search list, or slider.
  • An interrupted session can be resumed. To use a different range or order, remove the saved progress and start a new session.
  • Item notes can be viewed and edited while studying. iOS speech and automatic advance are also available.
  • Completed and interrupted sessions appear in Study history, where they can be deleted individually or in a selection.

Using quizzes

  • Choose a deck and either all items or incorrect items, then set the number or percentage of items to include.
  • After submitting or ending a quiz, you can review the number correct, score, elapsed time, and incorrect answers.
  • An in-progress quiz can be resumed from its saved position.
  • In Quiz history, filter and sort completed results or retake the same item set.
  • Delete quiz records by swiping an entry to the left or by using selection mode.

Using notepads

  • Notepads are separate from decks and let you write a title and formatted body text freely.
  • Saved notepads can be searched, sorted, and deleted individually or in a selection.
  • A notepad can be exported as a PDF or read aloud using iOS speech.
  • Use the Excel template to prepare multiple notepads and import or export them together.

Using PDF and Excel

  • From a deck's More menu, export all or selected items as a worksheet and answer-key PDF.
  • Export the Excel template first, keep its structure, and then import the completed .xlsx file into a new or existing deck.
  • When importing Excel data, choose Merge to keep existing items or Replace to replace the current deck's items.

How to contact support

  • Contact us at the support email above.
  • Include the app version, device model, iOS or iPadOS version, and a description of the issue.
  • If possible, include screenshots and the steps that led to the issue.
  • Tell us whether the issue concerns decks and items, study or quiz history, notepads, PDF or Excel, or a .vocadio file.
  • Remove passwords, full item contents, personal notes, and any other information you do not want to disclose.

Data and backups

  • Vocadio stores decks, items, activity history, and notepads on your device by default.
  • Before deleting the app, back up any data you need to a .vocadio file using Data Export in Settings.
  • Password protection is optional during export. A password-protected file cannot be recovered if you forget its password.
  • We recommend keeping a separate copy of the original file before importing data.

Speech notice

Speech uses voices installed on your device and its language settings. Pronunciation of numbers, symbols, or sentences containing multiple languages may vary depending on the device's speech settings.
