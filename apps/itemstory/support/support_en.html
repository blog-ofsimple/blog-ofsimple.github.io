User guide

Getting started
  1. Open Category and create a category, or load a template and edit its fields.
  2. Choose the default category if you want it selected first when adding an item.
  3. Open Add, select a category, enter an item name, and complete the fields you need.
  4. Tap Apply to save. The new record appears in All.

Only the item name is required. Other fields can be left empty so that older or incomplete information can still be recorded.

All menu
  • All: browse every active item. Use the category or tag chips, search, and sorting to narrow the list.
  • Repeat: review item names recorded at least twice, compare their history and changed values, and export the history as PDF.
  • Alert: review records that contain an alert date. The bell indicates that a local alert is currently scheduled.
  • Custom tabs: use the add menu beside the tabs to save reusable conditions. Tabs can be edited, deleted, and reordered.
  • Swipe an item left to move it to Trash, or use selection mode to move multiple items to Trash or export them as PDF.
  • For selected-item PDFs, choose whether to include images. If generation or sharing fails, the selection is retained so you can retry.
Category menu
  • A category acts as the input template for an item.
  • Add and reorder fields, rename the fixed item-name field, and configure currency, unit, or dropdown options where supported.
  • Available field types include text, tag, amount, number, phone, URL, email, image, date, event date, alert date, dropdown, switch, and checkbox.
  • An inactive category is hidden when adding new items, but existing item records are retained. Restore it from the Inactive tab when needed.
Add, view, and edit items
  • Select the category from the top of the Add screen. Its fields are displayed in the saved order.
  • Image fields can use the camera or Photo Library. Attached files are copied into app storage.
  • Tap an item in All to open its read-only detail view. The more menu provides Edit, Copy, individual PDF export, and Delete.
  • Copy creates a new draft from the current record; it is saved only after you apply the draft.
  • Changing the category lets you map values to the fields of the destination category.
Search, filters, and sorting
  • Basic search finds matching item values, including searchable text and tags.
  • Advanced search supports grouped conditions and all/any matching.
  • Custom tabs save conditions that you use repeatedly.
  • Sorting includes the built-in item-name and created-date options and compatible custom fields.
Stats menu
  • Period summarizes records in a selected date range.
  • Trend compares values by day, month, or year and displays charts where supported.
  • Custom statistics let you choose conditions and a calculation such as count, amount total, number average, or value change.
  • Tap a custom-stat result to review matching items in a paged list.
  • Use the PDF icon at the top to export the current period or trend report.
  • The event-date field is used as the statistical reference date when available; otherwise the record creation date is used.
Alerts
  • Add an Alert date field to a category, then enter a date in an item.
  • In Settings, choose the default alert time and how many days in advance to notify.
  • Local alerts require system notification permission and the in-app Notifications switch to be on.
  • Items excluded by Alert-tab conditions are also excluded from local alert scheduling.
Settings, backup, and Trash
  • Change the theme and app language without changing the currency already saved in a field.
  • Export an .ist backup containing categories only, all data, or items matching created-date and category filters. Password protection is optional.
  • Choose whether to include Trash, images, custom tabs, and custom statistics. Backup image quality changes only the exported copy, not the original images stored by the app.
  • Review item, category, and image counts before export, and review backup information before import.
  • Choose Merge or Replace when importing. Merge keeps existing data and skips matching records; Replace uses the imported data as the app data.
  • Deleted items move to Trash. Open Trash to preview, select and restore or permanently delete multiple records, or empty Trash.
  • Open Images in Settings to browse images currently stored by the app.

Keep important .ist files outside the app before deleting app data or uninstalling. Support cannot remotely recover local records without a usable backup.

Before contacting support

  1. Update Item Story and your operating system to the latest available version.
  2. Close and reopen the app.
  3. Check the related permission in system settings for photo, camera, or notification issues.
  4. For missing records, check the selected category, custom tab conditions, search conditions, sorting, and Trash.
  5. Create and verify an .ist backup before resetting data or reinstalling the app.

Include in your email

  • Item Story version
  • Device model and operating system version
  • App language
  • Steps that reproduce the issue
  • A screenshot or screen recording with private information removed
  • Whether the issue concerns items, photos, alerts, statistics, PDF, backup, restore, or Trash

Do not send backup passwords, full backup files, receipts, or sensitive photos unless support specifically requests a safe diagnostic sample.

Data and recovery

Core data is stored locally on your device. Support cannot remotely recover data that was deleted without a usable backup. Use Settings > Data Export to create .ist backups and verify important backups before deleting app data.
