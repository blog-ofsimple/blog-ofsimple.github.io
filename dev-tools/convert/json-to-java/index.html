JSON → Java 가이드

JSON 필드를 Java 타입으로 매핑해 POJO 혹은 record 템플릿을 생성합니다. 필수/옵션 필드와 기본값 전략을 안내합니다.

매핑 규칙

  • string → String, number → BigDecimal/Integer/Long
  • boolean → boolean/Boolean, array → List
  • 날짜 문자열 → LocalDate/LocalDateTime 패턴 지정

팁

  • 스네이크 → 카멜 자동 변환 옵션
  • Optional 사용 여부 선택
