Excel → JSON 가이드

엑셀 데이터를 표준 JSON 배열로 변환합니다. 헤더 행으로 키를 생성하고 날짜/숫자 타입을 자동 인식합니다. 개인정보 컬럼은 마스킹 옵션을 제공합니다.

권장 워크플로

  • 첫 행을 헤더로 사용하여 키 정의
  • 날짜 포맷은 YYYY-MM-DD 권장
  • 대용량(10MB+)은 시트 분리/컬럼 축소

FAQ

  • 누락 셀: null 또는 ""로 처리
  • 타입 고정: 자동 인식이 불확실할 때 옵션으로 지정
  • 보안: 모든 변환은 로컬에서 동작
